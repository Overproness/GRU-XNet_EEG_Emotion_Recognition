## Matched small neural controls

Use the unchanged pinned official CBraMod backbone and its author-supported **average-token pooling followed by one Linear(200, classes)** head. Compare pretrained/random42 × frozen/trainable encoder in each dataset/group. Both encoder conditions use training-mode dropout while fitting and evaluation mode at prediction, as the author trainer's model-wide training mode does. A frozen encoder runs without gradients; a trainable encoder receives gradients. This avoids changing encoder input mode between the paired conditions.

The [author trainer](https://github.com/wjq-learning/CBraMod/blob/b9e961003214326972c567eff390e75b0287e32a/finetune_trainer.py) motivates AdamW, separate head/backbone learning rates, cosine decay and clipping; [author settings](https://github.com/wjq-learning/CBraMod/blob/b9e961003214326972c567eff390e75b0287e32a/finetune_main.py) provide label smoothing and weight decay. This local finite-budget trial task is not an exact reproduction of their epoch budget, multilayer default classifier, datasets or published scores.

- Head initialization seed 4242, shared exactly across paired conditions of the same task; encoder initialization 42 for the random control. The pretrained backbone is the same pinned released checkpoint as before.
- Exactly **200 optimizer updates**, with six balanced original-observation draws per update: three per DEAP class or two per SEED-IV class. Sample with replacement and choose one of each observation's four ten-second windows uniformly. Keep the same observation/window sequence across every paired condition and learning rate. No augmentation.
- Trainable encoder rates **1e-4 / 3e-5**; frozen encoder has no optimizer group. The head rate is fixed for every condition at `0.001 * sqrt(6/256)` (approximately 0.00015309), following the author multi-rate formula. Frozen controls are run once rather than duplicated for a nonexistent encoder rate.
- AdamW weight decay 0.05, global gradient norm clipping at 1, label-smoothed cross entropy 0.1, cosine schedule over 200 updates with minimum rate 1e-6. Global clipping includes encoder gradients for full fine-tuning, so head trajectories need not match after updates.
- FP32, no AMP, explicit deterministic PyTorch mathematical attention for training/inference/replay. CPU/GPU/dropout seeds and independent NumPy observation/window streams are fixed. The synthetic resource pilot covers full backward updates and inference batch 16 on both native montages, peaking at 1,015,990,272 allocated tensor bytes. This excludes context/driver allocations and is not a convergence result.

These choices produce **24 trajectories**: eight frozen and sixteen trainable, with **48 checkpoint candidates** at updates 50/200.
