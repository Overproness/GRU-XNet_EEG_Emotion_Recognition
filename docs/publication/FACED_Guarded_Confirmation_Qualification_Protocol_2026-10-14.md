## Fixed scope and purpose

The new executor preserves the existing four alpha-100 source recipes: category median, availability-matched context Ridge, late EEG joint Ridge and distributed EEG joint Ridge. Its production roster is the exact previously published metadata scope: 33 reserved people, 297 unfamiliar and 462 familiar trials, 2,277 regional intervals and 3,036 predictions. Every exported record retains its genuine `confirmation` role and its correct arm. Manufacturing the signal inputs never changes protected identities to a manufactured participant role.

Qualification opens only the three already fitted source-state NPZs, original uppercase source-prior JSON and the qualified available-source vector snapshot. Exactly 979 × 3 × 150 = 440,550 source feature values are allowed; the one shared-missing source trial remains in the 980-row denominator. Numerical source predictions are compared against all 3,920 existing independent target-free fixtures at tolerance 1e-10. No cached source target, development-validation value, original rating or original recording is read. Metadata and existing prediction fixtures are public; snapshot/state/prior arrays stay private.

A separate manufactured reader traverses the entire real future metadata roster. It supplies fabricated 150-dimensional regional features, one engineered failed region, and resource counters representing the declared future byte scope. All 2,277 intervals and 3,036 method rows must complete. The resulting canonical lock is explicitly `manufactured_qualification`; a production rating gate rejects it. Those counters are **not measured protected transport or a throughput qualification**.

Two manufactured BDF streams, at 250 and 1,000 Hz, exercise the same selective signed-24-bit decoder, existing calibration, notch/filter/resampling/artifact control, unchanged QC and spectral feature path used by the prospective original reader. Each decodes exactly 30 scalp channels × 32 seconds, with partial record boundaries and no extra boundary samples. The generated integer arrays supply an independent count-byte reference. Fabricated headers preserve the applicable legacy aliases/scalp indices and documented unit literals; no actual original header is opened. The total fabricated decoded-count ceiling is 1,200,000 values. These streams qualify implementation behavior, not the protected recordings' quality or scientific validity.

## Production barriers

The new inactive executor contract binds scope and package hashes, complete public/code dependencies, current source-bundle fingerprint and runtime. It remains inactive and is not a replacement activation for any old proposal. Before an original callback, production requires an exact author-specific, saved, byte-bound access instruction for the `signal_prediction` phase; all six separately bound scope/contract readiness receipts; the unchanged runtime, fitted states and resource policy; and the entire 759-trial/66-file identity, channel, range, size/hash and resource metadata barrier. A boolean flag or old three-model activation is insufficient. The supplied Python safeguards enforce workflow order; they are not an OS security sandbox or cryptographic proof of who authored a receipt.

Before the first original stat/open, all 33 public header projections must agree with each person's exact selected scalp indices, aliases, acquisition rate, recording geometry, channel count, scalp-unit repair rule and finite calibration. The production reader subsequently checks actual paths remain in the intended workspace, rejects symlinks/escaping paths, authenticates original size and complete opaque data/event hashes, and verifies bound raw header bytes. Event bytes are transported solely for integrity and never decoded as annotations. Data decoding is restricted to the declared 32-second region and 30 scalp channels. Original size/mtime are checked during reads and all data/event files are hashed again after processing.

The fixed shared policy retains every trial. A known engineered QC failure in any one region sends context and both EEG recipes to the same source category prior; practical category medians always use that prior. Unknown flags, technical failures, nonfinite signal/features/predictions, changed inputs or resource failures stop the attempt. They never become missingness, trial exclusions, new targets or an automatic retry.

Every production prediction lock must include both arms and exactly 3,036 target-free canonical method rows, all four methods per trial, shared QC and state/input hashes. A separately authorized `item10_rating` phase requires independent lock qualification and **actual local Git blob-byte verification** for all three complete lock files; caller-provided `committed: true` flags do not suffice. This task creates no rating adapter activation or author instruction.

## Resources and evidence

Production ceilings are 10,800 seconds wall, 10,800 seconds CPU and 2 GiB process-private memory. All scalar/selected-byte/read-call/header/hash counters must equal the previously published exact metadata ceilings at completion. Integrity chunks are at most 1 MiB. A foreign numerical-library call cannot be preempted by these Python checks: an overshoot is detected on return, so this is not a guaranteed hard real-time limit. Numerical preprocessing retains the previously qualified 12-thread BLAS section; adding a differently threaded numerical path requires separate qualification.
