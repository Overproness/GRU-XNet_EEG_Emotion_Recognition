## Representation and fixed readouts

The existing 150-dimensional equal-window log Welch band powers are the reference. A single new covariance representation uses the same Hann/detrended windows and five frequency bands. Integrate real cross spectra and average the seven windows equally to obtain five 30×30 band covariance matrices. Their diagonals equal arithmetic-mean integrated Welch power. For each matrix C, use trace normalization and fixed 10% diagonal shrinkage: 0.9 C/trace(C) + 0.1 I/30. Apply the symmetric matrix logarithm, vectorize the upper triangle with sqrt(2) weights on off-diagonals, and append five log10 total-band-power traces: 2,330 features. Nonfinite/nonpositive energy or failed representation preparation holds the experiment; it does not create a retrospectively selected fallback.

These are trial-local log-Euclidean covariance coordinates, not a reproduction of an affine-invariant tangent-space paper or a new algorithm. Standardizing coordinates changes their geometric weighting. No jointly fitted reference covariance, validation statistics, ICA, participant alignment or pretrained encoder is used. Covariance and manifold representations already appear in EEG emotion/regression work. [Representation paper](https://arxiv.org/abs/2008.08633), [pyRiemann tangent-space documentation](https://pyriemann.readthedocs.io/en/latest/generated/pyriemann.tangentspace.TangentSpace.html).

Seven new fixed conditions are evaluated: covariance linear; context-plus-covariance linear; context kernel; spectral kernel; context-plus-spectral kernel; covariance kernel; context-plus-covariance kernel. Linear covariance uses the preceding EEG/joint regularizations, respectively 1,000 and 100, with source-only standardization and intercept; it has no alpha search. Kernel methods use Gaussian RBF kernel Ridge with fixed alpha 0.1 and a source-mean target offset. Standardize coordinates on exact source rows, divide each block by sqrt(block width), and choose gamma as the reciprocal median strictly positive squared distance among source pairs. Refit scaler, bandwidth and target offset inside every source fold. There is no validation-dependent hyperparameter selection or head/representation winner used to trigger another fit. [Kernel Ridge documentation](https://scikit-learn.org/stable/modules/generated/sklearn.kernel_ridge.KernelRidge.html).

Each condition has one main fit and five held-source-participant fits per rotation: 126 normal fits. Reuse the preceding quality-policy context/spectral/joint Ridge predictions and all source-prior controls; they add no fits. All predictions are clipped to the same 0–7 rating range. Save main training errors, source OOF errors, unseen/familiar validation predictions, source scaler/bandwidth statistics, exact source identities and linear-system residuals.
