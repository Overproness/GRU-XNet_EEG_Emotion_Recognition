# Independent qualification of saved full-source states

14 October 2026, Asia/Karachi. This bounded protocol independently checks the three existing full-source Ridge states and their existing category prior. It changes no fitted state, model, threshold, manuscript, participant/material assignment, research question or protected-data gate. Numerical access requires the root to freeze this protocol, its code/tests and the opaque-input declaration first. Preparing a declaration authorizes hashes and public metadata only.

The exact numerical scope is one previously qualified source snapshot with shape 979 × 3 × 150 (440,550 scalars), three final-state NPZ files, one source-prior JSON and 980 distinct cached source valence values. No raw samples, original ratings, validation values, protected values or additional fitted states may be decoded. The snapshot represents jointly available source trials; all three regional arrays from the one shared-missing trial remain skipped. No model is fitted or equation solved. Cooperative wall/CPU caps are 600 seconds each, with two BLAS threads. The first started ledger is preserved; a failure requires review and a separately declared continuation rather than an automatic retry.

All public receipts, source participant/material metadata, full-source state identities, available/missing trial order, snapshot/prior/state opaque hashes and manuscript/archive preservation bindings are checked before numerical private access. The declaration binds the exact allowlist. Source context is reconstructed independently in the fixed order: eight category indicators, three acquisition indicators, catalogue duration and trial ordinal. Each vector must match the historical context hash. EEG ordering is thirty named channels, each with delta, theta, alpha, beta and gamma powers; the bound historical feature definitions document this order. This check authenticates cached feature ordering and reconstruction; independent raw-signal or spectral-feature recomputation is a separate qualification.

Late EEG uses the cached late vector. Distributed EEG is the equal average of the three already-logged regional vectors. Each training EEG mean uses all 979 available source donors, matches its pre-target mean fixture and saved mean exactly, and imputes the single missing training EEG row. All 980 context/target rows are retained. Population means and variances, the constant-column scale rule and final context-scaler prefixes are independently checked. Moment comparison tolerances are relative and absolute 10^-12; hashes additionally check exact imputation means and historical context prefixes.

All candidate source CSV rows complete a role/identity/family/acquisition coverage pass before the first target conversion. The global pass must find exactly 11,760 agreeing source rows, 15,960 ignored rows and 980 distinct source identities, matching the bound pre-existing cached-target receipt. Other participants or arms are ignored before numerical conversion. Source repeated labels must agree, be finite and lie in [0,7]. Thus the distinct-target cap is 980 and the numerical row-conversion cap is 11,760; ignored targets are never numerically converted. The 980 retained labels are used only for existing-state stationarity and median verification, without source predictive scoring or any fresh selection. Operative plan_v2.json makes these resource counts explicit and binds the original unexecuted plan.json; it changes no scientific setting.

Let Z be the training matrix standardized with the saved moments, Zc its column-centered version and yc the centered labels. Check the saved coefficient b against `(Zc.T @ Zc)b + 100b = Zc.T @ yc`, with normalized maximum residual at most 10^-9, without solving this system or calling any producer fitting function. Independently check the saved intercept against `mean(y) - mean(Z) @ b` within 10^-10. Replay raw and [0,7]-clipped predictions using matrix multiplication and explicit per-row sums within 10^-10. Finite float64 states with exact dimensions, keys, positive scales, nonnegative variances and alpha 100 are required. The implementation imports no producer model or preprocessing functions.

Independently reconstruct global, coarse, category and familiar-video medians from the source labels and compare the saved prior exactly. Write 980 source fixtures containing category predictions, each model's training-state predictions and each model's shared-availability inference predictions. On the shared-missing source trial all three regression methods use the same category prediction at inference; training imputation predictions are kept separate. No errors or performance scores are computed from these full-source predictions.

Anticipated public outputs are the frozen declaration, first-attempt ledger, source prediction fixtures, per-state moment/stationarity/algebra discrepancies, imputation and prior checks, unchanged-input preservation receipt and completion hashes. A failure records its error without modifying previous evidence. Passing proves numerical consistency of these existing full-source states with the qualified cache and targets. It does not qualify reserved exports, certify predictive utility or future precision, independently validate target semantics, or settle general EEG model performance. The source/manufactured inference/export pipeline and raw backend remain separate dependencies.
