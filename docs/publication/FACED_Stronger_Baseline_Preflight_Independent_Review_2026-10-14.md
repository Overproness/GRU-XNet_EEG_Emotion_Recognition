## Model provenance and schedule

The code uses the previously author-checked `eegnet_control.py`/`eegnet_regression.py` port, not the separate generic EEGNet implementation. The original classifier backbone is authenticated by the pinned author-code and manufactured cross-framework audit. Scalar regression, trial averaging, source-channel scaling, residual offsets, MSE, AdamW and FACED temporal/artifact preprocessing are explicitly local adaptations. This is not a reproduction of an EEGNet-author emotion-regression benchmark or optimizer trajectory.

There are exactly four neural fits: two 200-epoch true/permuted capacity controls and two 360-epoch residual-model initializations. Checkpoints are 100/200 for capacity and 120/240/360 for the main models. The 360-epoch two-seed average is the only main endpoint; earlier checkpoints are diagnostics. Raw predictions are averaged before 0–7 clipping. Context@100 and training-category medians remain mandatory comparisons; context@100 is not described as an independently optimized context baseline.

Each of the ten prospective saved states is tensor-only reloaded on CPU with strict model geometry, finite tensors and spatial/head max-norm constraints checked. Fixed first/last training and held identities are recomputed from retained source windows with the corresponding source-only scaler and offset; recorded and reloaded predictions must agree at absolute tolerance 1e-4 plus relative tolerance 1e-5. That reload/forward work remains inside the charged neural-fit budget. It verifies saved state/CPU forward consistency on fixed subsets, not an independent architecture implementation or every exported prediction.
