# Full-width GRU-XNet and contextual-prior controls

Predeclared development study, 6 October 2026. No manuscript or main research-question change is approved. All prior experiment sources remain unchanged.

The machine-readable declaration is exported with the results. This phase reuses **grouping 1** of the completed repeated-material controls: participant seed 20261007, material seed 20261017. All 1080 SEED-IV trials and all 1264 retained DEAP trials receive one out-of-fold prediction per model and arm. The participant/video assignments and per-participant/class matching remain identical to the previous controls. Validation participants and videos are held out; test participants are held out in both arms. Test videos appear among other training participants only in the exposed arm. There is one optimizer initialization, held fixed across model/arm comparisons.

Four neural models are fitted in each cell: the **full-width dynamic GRU-XNet**, a **matched BiLSTM swap**, the **local CBSAtt implementation**, and **GRU-XNet plus a fixed contextual-prior logit offset**. This yields 360 SEED-IV and 320 DEAP fits. They use the historical 32/64/128 independent electrode CNN widths and 128-unit bidirectional recurrence. The matched swap changes recurrence only; its parameter count is larger. The local CBSAtt control retains its original global pooling and one-step LSTM, so it is a separate implementation control. It is not authenticated author code or a published-score reproduction.

The common physical 14 electrodes and first 40 seconds are retained. The STFT has actual 4–40 Hz bins (Hann 128, hop 64, no boundary padding), producing 37 frequencies and 79 time frames. No interpolation to historical 129×126 dimensions is used. Three pools leave four frequency bins and nine ordered recurrent time steps in the dynamic models. This is the full historical **architecture width**, with explicitly adapted inputs and output labels; it does not recreate the historical pooled augmented experiment or its 95.91% score. Input channel/frequency normalization uses only training trials. Full-trial offline filtering before cropping means this is not causal 40-second acquisition.

Each neural fit receives 200 balanced 12-trial AdamW updates, learning rate .001, weight decay .01, gradient clipping 1, deterministic FP32 computation and no augmentation. Validation occurs every ten updates; select maximum primary trial balanced accuracy, then minimum balanced log loss, retaining the first exact tie. The canonical participant/class/rank draw stream is matched across arms and models. GRU and GRU-plus-context have identical initial weights and parameter counts. This fixed first-pass budget does not establish convergence. Training/validation curves and checkpoint positions will be reported before deciding whether to predeclare longer controls.

Context uses Laplace-one class counts for each video among training participants; unseen videos receive the global training class distribution. **Every training row excludes all labels belonging to its own participant**, including from the global fallback. Validation and test context use only outer training labels. No validation/test ratings enter context features. The contextual prior and a learned context-only logistic calibration are both evaluated. The latter receives log-prior features, a training-only scaler and four C candidates (.01/.1/1/10), selected on the same validation set. GRU-plus-context adds log prior to EEG logits without additional parameters. This tests whether EEG residuals improve predictions beyond contextual controls, while allowing that finite-budget fitting may fail to extract available information. Training-video priors and unseen-validation priors have different distributions; this limitation is retained explicitly.

Primary tasks are SEED-IV neutral/negative/positive and DEAP individual binary valence. Secondary SEED-IV binary valence excludes neutral and conditions probabilities on negative/positive mass. Report all neural/context results and all predeclared exposure, architecture and incremental-EEG contrasts, for balanced accuracy **and balanced log loss**. Paired participant and crossed participant/video percentile intervals use 10,000 fixed draws, with observed-cell class denominators and native-emotion/video strata as in the previous study. Intervals are conditional on fixed fits, one grouping and these development cohorts; comparisons are exploratory and unadjusted. Score changes do not isolate video identity from training content or difficulty, and this phase cannot establish joint multi-corpus negative transfer.

Synthetic-input resource checks and weight-mapped forward comparisons precede fitting. Preflight independent STFT checking identified float32 FFT precision differences on some recordings: STFT/log1p now run in float64 and are stored as float32, with the original numerical tolerance retained. No model was fitted before this preparation correction. All input/source/config/split/initial-state/sampling/checkpoint/prediction hashes are bound. Every selected checkpoint is independently replayed on training, validation and test data; all context candidates are refitted, and every original trial must be tested exactly once. Raw EEG, checkpoint weights and third-party reference code remain outside the public evidence export.
