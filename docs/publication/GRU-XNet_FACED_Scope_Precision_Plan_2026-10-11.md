# FACED scope, closest methods and fixed evaluation plan

11 October 2026, Asia/Karachi. **The scope audit and fixed baseline/selection/precision proposal are complete. Fitting, confirmation access and manuscript-question adoption remain held.** The feasible claim is retrospective individual valence predicted from offline marker-relative late EEG, conditional on supplied study metadata, evaluated across catalogue source-title families. Physical footage independence, display/audio latency and a distinct conference contribution remain unestablished.

The [public packet](../../results/development/faced_scope_precision_2026-10-11/README.md) contains a committed-before-calculation declaration, bound public inputs, reproducible calculations, source receipts and an independent scalar audit. ## Stimulus and timing scope

All 3,444 previously qualified numeric marker spans were checked from their public projection. Among the 2,829 spans eligible under the fixed global exclusions, the shortest duration is 34.106 seconds. The nominal marker-relative 32-second input starts at least 2.106 seconds after the start marker, and the 28-second core starts at least 4.106 seconds after that marker and ends two seconds before the end marker. Native integer endpoint flooring can move these starts earlier by less than four milliseconds, leaving conservative margins of 2.102/4.102 seconds. Included marker duration differs from nominal catalogue duration by −0.479 to +0.802 seconds. These are marker-relative observations, not measured playback latency or alignment to an emotional scene.

The grouping unit is the normalized catalogue source title. Clips 7/8 share *The Shining* and remain a single protected family; neutral clips 13–16 share *Blue* and stay outside the primary population. Clip 22 remains globally excluded because its versions have different marker durations and unauthenticated footage correspondence. No original stimulus movie hashes, playback execution logs or physical clock calibration were authenticated. Different titles can still have related semantics or reused content, and source catalogues overlap broader EEG/media resources. The scope is resolved by limiting claims to marker intervals and catalogue titles; stronger timing/content claims require original media/execution evidence.

Keep FACED's item-10 individual retrospective valence on 0–7 and the existing non-neutral elicitation population. The context branch receives assigned category, acquisition group, nominal duration and presentation ordinal only when supplied at inference. Category describes the experiment's intended elicitation, not the held participant's experience. Familiar-film source medians are an additional familiar-arm comparator, with no outcome lookup from reserved films. The 70/20/33 participant roles, 14 development families, eight protected families, acquisition policy, target eligibility and manuscript are unchanged.

## Closest-method distinction

The [detailed review](../../results/development/faced_scope_precision_2026-10-11/closest_method_review.md) distinguishes verified methods from abstract/code-path evidence.

[Gerster et al.'s FACED preprint](https://www.biorxiv.org/content/10.64898/2026.06.12.731889v1) already tests stimulus confounding, individual versus assigned reports and linear/CLISA controls. Its publisher API confirms v1 dated 16 June 2026. Full PDF and publisher-listed JATS still return 403; Europe PMC supplies metadata without a full-text/PDF route. Its precise individual target and complete material splits remain unaudited. We cannot establish novelty over it.

[Kong et al.](https://arxiv.org/html/2610.03618v1) tests source video/time priors and small EEG-fNIRS residual gains for second-by-second responses to familiar videos; it explicitly excludes unseen-video results and already recommends crossed participant/video evaluation. [Wang et al.](https://arxiv.org/abs/2610.02796v1) tests shared trajectories and label-free synchrony calibration on the same familiar videos, with an arousal-focused negative search. Retrospective FACED valence across distinct catalogue titles is an operational difference; neither a split nor another failed encoder grid establishes the contribution.

The [CL-CS publisher abstract](https://www.sciencedirect.com/science/article/pii/S1746809425000229) claims generalization to new people and novel stimuli. The pinned [released repository](https://github.com/VCMHE/CL-CS/tree/004293e646ad4fa4e2642405440dac578fa70757) contains a thirteen-file code ZIP. Its inspected default loader/classification/pretraining paths use a SEED-like 15-person/15-video setting, shared assigned labels and participant-held-out indexing that retains the video axis. This does not authenticate its published FACED/novel-stimulus protocol or provide an individual-valence regression recipe. It also does not prove that the paper never held stimuli out. Only code text was read; no external code or bundled original-author validation outcomes were executed/opened.

## Precision from existing development predictions

The analysis guards identities across all 63,840 already-public prediction rows before outcome conversion and retains every fallback. Nine fixed contrasts reproduce their earlier paired means. Each rotation uses the same twenty validation people and six overlapping development families, so the three panels are not independent experiments.

| --- | --- | --- | --- |
| Spectral joint versus metadata Ridge | −0.0062 / +0.0332 / +0.0995 | 0.090–0.138 | 0.058–0.094 |
| Covariance joint versus matched context kernel | +0.0388 / +0.0773 / +0.0874 | 0.094–0.115 | 0.052–0.092 |
| Covariance joint versus stronger metadata Ridge | +0.0290 / −0.0011 / +0.0434 | 0.088–0.178 | 0.073–0.097 |

These projections assume an additive participant/film/residual variance model. Several six-film method-of-moments components are negative: raw estimates are retained and clipped to zero only for the illustrative projections. The fixed-roster half-width uses the development six-film participant-mean SD as a proxy, not observed eight-film precision. All projections omit final training/selection uncertainty, and the six-film validation panels omit Fear/Inspiration present in the protected roster. They are **not validated power, coverage or a claim that confirmation will succeed**. Doubling assumed standard deviations raises the overall nominal detectable-gain range from 0.088–0.178 to 0.176–0.356.

For the covariance-versus-Ridge contrast in rotation 1, the assumed eight-film variance floor alone gives a nominal detectable effect of 0.136 even with indefinitely many participants. Other panels have negative film estimates; their plotted zero floor is a truncation convention, not evidence of no material variation. See the [planning figure](../../results/development/faced_scope_precision_2026-10-11/precision_scenarios.png). Sampling both factors matters, as established by [Westfall, Kenny and Judd](https://pubmed.ncbi.nlm.nih.gov/25111580/); crossed-resampling theory does not guarantee small-film coverage here.

The feasible primary endpoint would be the gain for new participants **on the fixed eight-family roster**, with a single frozen model/context comparison and an approximate t interval over 33 participant means. The 297 nominal unfamiliar-film trials contain 264 participant/family cells; clips 7/8 must first average within family. Broader material-resampling intervals remain descriptive. The 0.15 margin is an engineering screen, with 0.05/0.10/0.15/0.25 sensitivity, not a validated clinical/perceptual threshold. A roster-conditional upper bound would not establish absence of neural emotion on arbitrary films.

## Fixed baseline and selection proposal

Retain source global/category/coarse-valence priors, strong metadata Ridge/kernel controls, all existing spectral/covariance anchors and a separately authenticated scratch EEGNet regression reference. The current classifier audit does not authenticate a scalar regressor. Pair the neural EEG-only reference with a source-context residual version, use the same original trials and source-only transforms, and compare against the stronger no-EEG control as well as its matched branch.

The bounded diagnostic has twelve fits on rotation 0 (two readouts × three learning rates × two fixed seeds), then eight fits transferring each readout's chosen learning-rate/checkpoint schedule unchanged to rotations 1/2. Fixed schedules, seed ensembles, checkpoint/tie rules, learning flags, unavailable-EEG behavior and a six-GPU-hour/20-fit cap are specified in the proposal. **Nothing is launched.** It is a baseline qualification, not a transformer/foundation-model search. Current anchors fail the existing 0.15 lead screen against the strongest context.

If a qualified lead and approved question later support confirmation, the proposal fixes source-only selection on the 90-person/14-family development pool using five participant folds × seven two-family folds. It specifies 280 context regression/kernel fits, 105 source-prior constructions, a conditional 70-fit fixed-recipe neural qualification and two final ensemble fits, with a separate 24-GPU-hour cap. These adaptive development scores do not become external performance claims. Freeze one joint recipe and one strongest context recipe, prediction hashes and analysis before any protected target is joined. If there is no qualified lead or a resource/numerical failure, retain the hold.
