# Source-only learning and baseline protocol — 6 October 2026

This phase addresses whether the prior full models learned adequately, checks an authenticated EEGNet architecture baseline and repeats source-panel learning across groupings and initializations. It changes neither the manuscript nor the main research question. All recipes below are frozen before real fitting.

There are **96 fits**: 16 memorization checks and 80 source learning curves. The two datasets retain their different targets: SEED-IV neutral/negative/positive, DEAP individual binary valence. Use fixed session 1 / rotation 0 / fold 0 in each dataset; SEED-IV covers session 1 only. Use both previously declared source training arms and their identical source-validation trials. The model receives only training and validation rows. The outer-test rows are recorded to check disjointness and are never evaluated or used to construct a normalizer, target feature or selected checkpoint.

**Learning curves:** GRU-XNet, matched BiLSTM, local CBSAtt and EEGNet-8,2. Run both learning rates, 0.001 and 0.0003, for 1,200 constant-rate AdamW updates with weight decay 0.01, clipping 1 and balanced 12-trial batches. Retain dropout 0.5, deterministic CUDA and FP32; use no augmentation, scheduler, AMP or early stopping. Observe full training and source-validation performance every 10 updates through 200 and every 50 thereafter. Report the 200/600/1,200 positions from the same trajectory, plus the selected and final states. Source selection uses maximum balanced accuracy, then minimum balanced log loss, then the first tie. Both learning rates are reported; do not select a globally preferred recipe from these panels and reuse it across outer folds whose test participants appeared in those panels.

**Independent source-panel checks:** GRU and EEGNet use a complete two-grouping by two-initialization factorial: existing grouping 1 and 2, initializations 42 and 91, both arms and learning rates. The local reference and BiLSTM use grouping 1 / initialization 42. Within an architecture, initialization is paired across arms/groupings and canonical source draw streams are paired wherever metadata permit. These checks reuse the same cohort and incomplete source-validation panels; they do not constitute complete out-of-fold test confirmation or independent human replications. Report descriptive results without claiming population confidence intervals.

**Memorization:** each of the four models and both corpora receives twelve distinct, class-balanced training trials chosen by a fixed metadata hash, separately using original labels and a fixed count-preserving permutation. Run 400 updates on the entire tiny batch, with normalization fit to that batch and all declared dropout/constraints retained. Save every outcome. Training BA at least 95% and balanced log loss below 0.15 is a descriptive capacity criterion; failures do not cause removal or success-based retraining. Learning permuted labels would show memorization capacity, not physiological emotion information.

**Input/baseline fidelity:** full models use the previously independently verified common14, first40-second logSTFT; normalization uses only source training trials. EEGNet receives the same verified physical waveform prefix, with source-only channel mean/std. Representation differences prevent an architecture-only ranking. The [authors' code](https://github.com/vlawhern/arl-eegmodels/tree/4a512e503198db2010848813ead9afbf8cd54c97) is pinned and executed unchanged using TensorFlow 2.10.1 on CPU. An isolated workspace NumPy 1.23.5 copy bypasses the existing environment's NumPy 2 import incompatibility; installed environments are untouched. The PyTorch port matches both binary/three-class outputs, dropout-zero deterministic training, BatchNorm moving states, constraints and parameter counts. It preserves asymmetric padding, channels-last flattening, Keras Glorot fan conventions and both max-norm constraints after every update. This authenticates architecture/operator behavior, without reproducing author RNG, optimizer trajectories or published scores. Original EEGNet paper: [Lawhern et al.](https://arxiv.org/abs/1611.08024).

**Reproducibility:** hash-bind all fitting sources, earlier cache/config identities, the author-code audit, source splits, scalers, initial/final/selected states and probability artifacts. Independently replay final and source-selected checkpoints and independently calculate balanced accuracy and class-mean log loss. For earlier full models on grouping1 / initialization42 / learning-rate0.001, require exact state reproduction at the earlier selected step and matching original source-validation histories/training batch losses through update 200. Read no prior test probabilities. Differences stop interpretation and remain recorded. Replay is not a complete rerun of optimization trajectories.

Broad outer-test repetitions will require a separate declaration with valid per-fold source selection. No convergence, novel method, absence-of-EEG-information, joint negative transfer or conference-readiness conclusion follows from this diagnostic. A changed research question still requires a concrete proposal, author approval and an immediate new archive of the then-current paper.
