# Post-hoc source BatchNorm diagnostic — 6 October 2026

This supplement is explicitly **post-hoc**: early source learning curves were already inspected. Longer training improved capacity but training evaluation accuracy fluctuated and validation loss worsened. The declaration lists every completed fit available at that point. No outer-test outcome is consulted, and none of the original learning curves, optimizer recipes or selected checkpoints is changed.

Evaluate **160 cases**, the originally selected and final states of all eighty source-curve fits. Keep every learned parameter fixed. Recalculate the three BatchNorm layers in feed-forward order, using only each fit's full source training population. Disable dropout and use evaluation mode throughout. Capture the input to each BatchNorm layer, accumulate float64 sums/squares across source trials and activation locations, then replace its running mean and population variance, with a variance floor of 1e-12. Later layers see the recalibrated earlier layers. Every source trial has equal weight, including the actual imbalanced source target distribution. This differs from the balanced sampled mini-batch distribution used during fitting.

Retain source training and validation probabilities before and after, BA and balanced log loss, changed moments and source-trial identities. Neither validation nor outer-test inputs determine moments. The training-only input normalizer, learned affine parameters, selected optimizer checkpoint and model parameters remain unchanged. Source-validation outcomes describe the diagnostic; they do not select a global recipe for later outer folds.

Independent verification reconstructs all moment arrays exactly, checks learned parameters unchanged, replays every after-calibration probability and independently computes metrics. Public probability records support metric and contrast checking; exact moment reconstruction additionally requires the local waveform cache and selected/final weights. Preserve all unsuccessful outcomes. This is a normalization diagnostic, not a proposed novel method, population-generalization estimate, research-question change or optimization convergence guarantee.
