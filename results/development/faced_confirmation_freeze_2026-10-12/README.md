Prepared before simulation in Git `a70f71553`. This packet selects a current exploratory claim for review and freezes a candidate analysis/information contract. It **does not activate protected data, fit final source models, adopt a manuscript question or establish independent confirmation**.

`contract.json` contains exact metadata-only source/confirmation identities and catalogue groups, the primary whole-recipe comparison, mandatory matched-context secondary, shared unavailable-EEG fallback and prediction-before-rating requirements. The current backend comprises guarded pure helpers, not end-to-end original-file extraction or final-model fitting. All empirical/approval gates are false.

`precision_plan.json` freezes analyst-chosen variance/gain scenarios. The completed synthetic study generates 4,096 matrices, 2,097,152 bootstrap means and 48 summaries. No empirical variance, EEG array, cached target/prediction file or protected value is used. The 0.045 assumption is motivated by an already published development mean; the study is not blinded to those aggregates. The 0.15 scenario is not a clinical/perceptual margin. Larger layouts are hypothetical, not newly available data.

`precision_receipt.json` and `precision_verification.json` report completed synthetic-only work and aggregate checks. `precision_gate_passed` remains false: simulated exclusion frequencies are not FACED power and do not clear the empirical continuation hold. The figures use these authenticated synthetic summaries only.

There are 41 passing metadata/synthetic guard tests across the contract and precision study. The independent review recounts all synthetic records/summaries and separately replays 48 seeded matrix fixtures and 24,576 bootstrap means. Original manuscripts, prior numerical packets and the historical report remain preserved.
